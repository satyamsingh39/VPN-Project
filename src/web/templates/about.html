ℹ️ About the Project

🔍 Overview

Modern cybersecurity and network management systems rely heavily on traffic classification. However, encryption protocols (TLS, SSH, VPNs) render traditional packet payload inspection ineffective. This system uses statistical flow characteristics extracted from telemetry (packet count, flow duration, sizing, and inter-arrival timing statistics) to classify encrypted flows without decrypting them.

🛠️ Models Used

VPN Detector

Random Forest Classifier — binary detection of VPN vs. Non-VPN traffic.

VPN Application Classifier

XGBoost Multiclass — classifies VPN traffic into 7 application types.

Non-VPN Application Classifier

XGBoost Multiclass — classifies non-VPN traffic into 7 application types.

📁 Datasets

  • VPN Dataset: Features flows captured over VPN sessions encompassing Browsing, Streaming, VoIP, Mail, Chat, P2P, and File Transfer.
  • Non-VPN Dataset: Standard network flows recorded directly without encryption wrapping.
  • Combined Dataset: ~59,706 labelled flow records for end-to-end evaluation.

📊 Pipeline

A Hierarchical Classification Pipeline routes flows dynamically. The first stage (VPN Detector) performs binary classification (VPN vs. Non-VPN), and redirects records to the target application-level classifier, substantially optimising multi-class prediction accuracy.
