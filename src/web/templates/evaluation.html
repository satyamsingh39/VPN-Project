📜 Research Evaluation Summary & Discussion

Key Technical Observations

1. Stage-1 VPN Detection Robustness: The binary Stage-1 Random Forest detector achieves an excellent accuracy of {{ "%.2f" | format(eval_data.summary.vpn_detection.accuracy * 100) }}% and F1 score of {{ "%.2f" | format(eval_data.summary.vpn_detection.f1_score * 100) }}%. Only {{ eval_data.stage_error_analysis.stage1_error_pct }}% of all network flows are routed to the wrong secondary classifier branch.

2. Stage-2 Degradation & Error Cascade: End-to-end hierarchical accuracy is {{ "%.2f" | format(eval_data.summary.hierarchical_classification.accuracy * 100) }}%. The ~7.86% drop between Stage-1 and final performance is predominantly driven by multi-class application confusion within the encrypted VPN branch (e.g., distinguishing between VPN-BROWSING and VPN-STREAMING).

3. Weighted vs. Macro F1 Disparity: Weighted F1 ({{ "%.2f" | format(eval_data.summary.hierarchical_classification.weighted_f1 * 100) }}%) significantly exceeds Macro F1 ({{ "%.2f" | format(eval_data.summary.hierarchical_classification.macro_f1 * 100) }}%). This gap reflects class support imbalance in the benchmark dataset; highly populated classes (e.g., BROWSING) perform extremely well, whereas minority classes (e.g., P2P) exhibit higher error rates.

4. Confidence Score Calibration: Incorrect predictions exhibit noticeably lower confidence scores (average ~0.76) compared to correct predictions (average ~0.96), validating that model probability outputs serve as a reliable indicator of prediction certainty in live network deployments.
